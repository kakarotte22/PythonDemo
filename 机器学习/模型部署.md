# 模型部署（XGBoost 批量打分）

使用 `pandas_udf` 将训练好的 XGBoost 模型广播到各 Executor，对全量用户特征表进行批量打分。

## 完整代码

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import pandas_udf, col
from pyspark.sql.types import DoubleType
import logging
import sys

logging.basicConfig(level=logging.INFO)

spark = SparkSession.builder.appName("du_risk_xgb_score").getOrCreate()

# 从任务参数获取分区日期，如 "20260517"
pt = sys.argv[1]
print(f"pt: {pt}")

# -------------------------------------------------------
# 1. 读取模型元数据
# -------------------------------------------------------
meta_row = spark.sql("""
    SELECT booster_json, feature_names
    FROM du_risk_training.model_train_skills_predictions_train_booster_20260511_144609_059
    LIMIT 1
""").collect()[0]

booster_json = str(meta_row['booster_json'])
feature_names = str(meta_row['feature_names'])
fts = [f.strip() for f in feature_names.split(',')]
print(f"入模特征数量: {len(fts)}")

# -------------------------------------------------------
# 2. 读取全量用户特征（分区表）
# -------------------------------------------------------
df = spark.sql(f"""
    SELECT *
    FROM du_risk_training.dw_risk_model_account_risk_level_fts_label_v1_df
    WHERE pt = '{pt}'
""")

# -------------------------------------------------------
# 3. 定义打分 UDF，通过广播变量传递模型和特征列表
# -------------------------------------------------------
bc_booster_json = spark.sparkContext.broadcast(booster_json)
bc_fts = spark.sparkContext.broadcast(fts)

@pandas_udf(DoubleType())
def score_udf(*cols):
    import xgboost as xgb
    import pandas as pd

    _booster_json = bc_booster_json.value
    _fts = bc_fts.value

    chunk = pd.concat(list(cols), axis=1)
    chunk.columns = _fts

    booster = xgb.Booster()
    booster.load_model(bytearray(_booster_json.encode('utf-8')))

    sub = chunk.fillna(-1)
    dmat = xgb.DMatrix(sub)
    prob = booster.predict(dmat)
    return pd.Series(prob.astype('float64'))

# -------------------------------------------------------
# 4. 批量打分
# -------------------------------------------------------
df = df.withColumn('prob', score_udf(*[col(f) for f in fts]))

# -------------------------------------------------------
# 5. 保存结果（只保留 user_id 和 prob）
# -------------------------------------------------------
df.select('user_id', 'prob').createOrReplaceTempView("tmp_score_result")

# 若目标表不存在则自动建表
spark.sql(f"""
CREATE TABLE IF NOT EXISTS {output_table} (
user_id STRING,
prob DOUBLE
)
PARTITIONED BY (pt STRING)
""")

print('开始保存打分结果...')
spark.sql(f"""
    INSERT OVERWRITE TABLE du_risk_training.dw_risk_model_account_risk_level_v1_score_df
    PARTITION (pt = '{pt}')
    SELECT user_id, prob
    FROM tmp_score_result
""")

print(f'打分完成，结果已写入分区: pt={pt}')
spark.stop()
```

## 关键设计说明

| 设计点 | 说明 |
|--------|------|
| 广播变量 | `booster_json` 和 `fts` 通过 `broadcast` 分发，避免每条记录重复序列化 |
| `pandas_udf` | 向量化执行，比普通 `udf` 性能更好 |
| `fillna(-1)` | 与训练时保持一致的缺失值填充策略 |
| 分区写入 | 使用 `INSERT OVERWRITE ... PARTITION` 支持幂等重跑 |
